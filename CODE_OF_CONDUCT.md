# Code of conduct

Be respectful, constructive, and patient. Welcome people of different backgrounds and experience levels. Discuss code and ideas without personal attacks. Harassment, discrimination, threats, sexualized behavior, and publishing another person’s private information are unacceptable.

Maintainers may edit or remove harmful content, close discussions, or limit participation when necessary. Enforcement should be proportionate and consistent. For sensitive conduct concerns, use GitHub’s platform reporting tools; do not post private information in a public issue. Ordinary project discussion can happen in GitHub issues and pull requests.
